# Scheduler Web Application (MVP Version 1)

Aplikasi pengelola waktu dan ruang belajar mahasiswa berbasis teknik saintifik (Pomodoro Timer & Blurting Active Recall).

## Panduan Instalasi & Fresh Clone
1. **Clone Repositori:**
   git clone https://github.com/sazkiaherfi-dev/scheduler-projek.git
   cd scheduler-projek/back-end

2. **Instalasi Dependensi:**
   npm install

3. **Sinkronisasi Database:**
   npx prisma db push

4. **Menjalankan Unit Test:**
   npm test

5. **Menjalankan Aplikasi:**
   npm start
   (Akses melalui browser di http://localhost:3000)
